# LoL Trainer (friends test build)

A League of Legends practice tool with an aim trainer (Ezreal) and a dodge trainer.

## Install
1. Download **LoLTrainer.exe** from the [latest release](../../releases/latest).
2. Run it. Windows may show "Windows protected your PC": click **More info -> Run anyway** (the launcher is not code-signed).
3. Press **Install** (about 2.1 GB download). The launcher keeps the game up to date: press **Update** when it says one is available.

## Play
Pick **Practice tool**, **Aim trainer** or **Dodge trainer**. In game: right click to move, D Flash, F Ghost, F7 start a round,
F8-F11 settings, F12 leave the mode, Esc options.

## Feedback
**Feedback files** opens the folder with crash reports and your round history (aim_history.csv, dodge_history.csv); send those along with
what felt off.
